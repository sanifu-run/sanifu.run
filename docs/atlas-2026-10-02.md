# Atlas page — 2026-10-02

The approved 3D Atlas is now packaged as the static `/atlas/` page, with a homepage link from the portfolio section. The refined design keeps white polished spheres, Sanifu crimson, commit-based sizing, creation-date layout, foreground labels, language artwork, search, linked year filtering and All years. A compact header, rounded detail card, readable gesture help, zoom/reset buttons and a repository list improve navigation. Portrait focus framing keeps the selected mascot visible above its details.

## Structure

- `atlas/`: ready-to-serve HTML, bundled JavaScript/CSS, public repository snapshot, language assets and credits.
- `tools/atlas/`: editable React/Three.js source and pinned dependency lock. Run `npm ci`, then `npm run build` in this directory to regenerate `atlas/`. `npm run verify` checks static integration. Build output belongs in the repository because GitHub Pages serves the root directly. No new build service or runtime CDN dependency.
- `design-qa.md`: visual comparison and local browser evidence.

The snapshot contains 156 public, nonfork repositories and was generated on 2026-10-02. Its dominant-language metadata and default-branch commit counts are a snapshot, not a live feed. Replacing `tools/atlas/public/atlas.json` and rebuilding updates it. The existing site analytics ID runs on Sanifu hostnames only; local previews do not send analytics.
