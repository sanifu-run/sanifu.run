# Sanifu identity

Founder approved the ascending-block Sanifu logo image on 2026-09-27. The unchanged local reference is `docs/design/v1/sanifu-logo-approved.png`; the production copy is `assets/brand/sanifu-logo-approved.png`. Three rounded blocks rise along curved connections to a top dot, paired with a lowercase wordmark. The favicon uses this mark. The earlier interlocking ribbon artwork remains local for history and is excluded from the public repository.

Reference: docs/design/v1 is preserved. Palette: crimson #b40020, red #ef2446, white #ffffff, black #000000. Use a clear sans-serif system stack, ample space and rounded action controls. White logo on crimson/dark surfaces. Never add a registered trademark symbol. Maintain clear space at least half the mark height; never stretch.

The approved PNG is the production visual. The local v1 design directory is preserved exactly and excluded from the public repository. The reference video is not enabled in production until rights and Sanifu-hosted delivery are verified. No remotely hosted commercial font is included.
