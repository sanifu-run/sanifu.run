The process, without the interactive map

  1. Prepare with Anza: a repeatable place to build.
  2. Plan with Foundry: define scope and observable checks.
  3. Build with Kazi or a direct AI harness: make one bounded change.
  4. Review with an independent reviewer; APRL is the planned broker. Review the exact candidate before a PR, then honor GitHub checks.
  5. Release through Foundry: merge and deployment are separate decisions.
  6. Improve in AMOS: use the app, inspect feedback and choose the next change.

These tools illustrate evolving architecture. Your project determines which tools you need.
